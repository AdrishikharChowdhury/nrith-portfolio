# Grand Theft Developer

A Next.js App Router portfolio inspired by GTA VI's layout and motion. It is a fan-made concept and is not affiliated with Rockstar Games.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000).

All page copy lives in `CONTENT.md` and is mirrored in `src/content.ts`. Artwork belongs in `src/assets/` or `public/assets/`, depending on whether it is imported by Next.js or used as a runtime URL.

## Validation

```bash
npm run lint
npm run build
```
